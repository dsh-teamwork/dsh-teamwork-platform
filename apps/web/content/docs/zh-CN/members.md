登录后，团队的模型、预设和插件会出现在 DSH 里，与你自己的配置并存。在控制台里，团队打开就是**首页**：在你的 DSH 接入之前，首页最上方是接入步骤，即在电脑上的 DSH 里登录 Teamwork，再把浏览器（**我的 DSH**）或手机 App 和这台电脑配对，每一步完成后会自动勾上。下面显示你近 30 天的调用和预算，以及团队最近的更新；**预设和插件**列出团队分享的内容：先是团队推荐的（已在你的 DSH 里），再是成员分享的，按使用人数排序；**在我的 DSH** 显示会同步到你 DSH 的内容，**我分享的**显示你分享的内容；**模型和用量**列出团队的模型和单价，并显示对你生效的额度、每个模型和每天花了多少积分，以及你最近的调用，可导出这段时间的 CSV。

## 从团队预设开始

用团队预设**新建会话**，或运行 `/teamwork new <id>`。预设会带上它的模型、必需工具和锁定的插件；缺少什么，DSH 会在开始前提示你。

会话保留开始时的预设版本。要使用更新后的预设，请新建会话。

## 使用团队模型

团队模型会出现在你的模型列表中。调用经团队服务器转发，你的电脑不需要密钥，并受团队预算约束。控制台的**模型和用量**列出每个团队模型的单价和你的用量。

## 安装锁定的插件

运行 `/teamwork plugins` 查看预设依赖哪些插件，再用 `/teamwork install <id>` 预览精确版本。确认之前不会安装任何东西。

## 添加预设或插件

在**预设和插件**里，点成员分享的条目旁的**添加**。下次同步后它会出现在你的 DSH 里，之后自动跟随最新版本；如果你固定在了旧版本，这一行会显示**更新**。点开一项可以看它需要什么（模型、工具和插件，以及你有没有），可以固定某个版本，也可以从你的 DSH 移除。团队推荐的已经在你的 DSH 里，除团队助理外也可以移除。在**在哪些 DSH 上**里取消勾选某台电脑，这一项就不会同步到那台；其他内容会同步到你登录的每台 DSH，包括以后新接入的。在 DSH 的 Teamwork 面板里也能看到团队的其他预设和插件，点**安装到这台**只装到当前这台。DSH 执行插件安装前仍会征求确认。

## 分享你自己的

点**新建预设**或**导入预设**，或在插件标签页点**上传插件**。通过校验后，所有人都能在预设和插件里看到它，它也会添加到你自己的 DSH。点开它可以看有多少人在用、发布新版本或下架；已经在用的人会保留下架的条目。只给自己用的配置可以留在本地。

## 向团队助理提问

每个团队都有一个助理预设。用它开一个会话，询问团队的资源、你的用量、预算、或成员。说出你想要的预设，它会起草完整的内容（人设、工作方法、模型和工具）给你看，你同意后发布到团队。管理员还可以让它管理团队配置，或把一个月的用量整理成页面。它会根据查到的情况建议下一步做什么。它要做的任何修改仍会先征求你的同意，它发布的页面在你共享之前只有你能看到。

## 在浏览器里使用你自己的 DSH

**我的 DSH** 在工作区里紧跟**首页**。每台在 DSH 里登录过 Teamwork 的电脑都列在这里；还没有时，它会说明怎么接入。这些电脑在侧栏里展开在它下面，在每个团队下都一样，在线的电脑前面是绿点；点**我的 DSH** 末尾的箭头可以收起。打开一台，它的会话就显示在侧栏旁边的一列，上方是电脑名、操作系统和设置按钮。先把这个浏览器和它配对一次：在那台电脑的 DSH 里打开 Teamwork 面板，选择**设备连接**并生成配对码，在这里输入，确认两边显示的安全码一致，再在电脑上批准。然后设置四位数的 PIN，离开超过十五分钟再回来时电脑会再次询问；只是网络断开重连不会再问。之后就能在浏览器里发起、查看和回应那台电脑上的会话，浏览器和电脑之间端到端加密。每台电脑都会显示是否在线、是否已与这个浏览器配对；离线的电脑在它重新运行 DSH 之前不能操作，连上之后页面会自动继续。

新会话在页面中间等你开始，布局和 DSH 一致：发出第一条消息之前，输入框上方可以选择这台电脑的工作区和预设（包括团队预设；电脑暂时无法运行的预设会说明原因），输入框底栏可以选择模型；不改就用电脑的默认设置。发出第一条消息后，会话就在原处展开。工作区默认是这个团队在那台电脑上的默认工作区，可在 DSH 的 Teamwork 面板**我的团队**里设置。会话标题旁的按钮（Ctrl+Shift+B）会在右侧打开会话侧栏，布局和用法与 DSH 一致：可以从左边缘拖动调宽、收起或全屏，标签页能分成两栏，每个会话的侧栏在这个浏览器里各自保留。其中的**文件**标签以树形显示工作目录，只读，可以按文件名搜索。文件在标签页里打开，上方显示路径：Markdown 会渲染显示，HTML 只显示、不运行任何脚本，代码带语法高亮和行号，图片直接显示；很长的文本滚到底部会继续加载，文件在电脑上被改动后会在原位置自动刷新。每次回复结束时，会有卡片列出本次改动的文件（带增删行数，鼠标停留可看对比，点击可在侧栏逐个审阅）和交付的文件。会话里提到的文件点一下也会在这里打开：步骤里的文件、回复里的路径（像 `src/app.ts:42` 会定位到那一行）、指向本地文件的链接，以及 agent 在回复末尾交付的文件。PDF 和 Excel 工作簿（不超过 16 MiB）会以预览打开（PDF 所有页面连续滚动、按面板宽度适配，工作簿逐表查看），预览在沙箱中绘制，无法以你的身份操作；电脑上的 DSH 装有 Office Kit 时，Word 和 PowerPoint 文件也能这样预览。它碰不到工作目录以外的任何东西，需要那台电脑上的 DSH Teamwork 插件是 0.16.0 或更新版本，预览需要 0.19.6，图片、长文本、自动刷新和改动卡片需要 0.23.0。回形针旁边的授权模式决定 agent 在那台电脑上能做什么：**只读**、**可写工作区**或**完全访问**，和 DSH 一致；切到完全访问前会请你确认一次。模型菜单按提供商分组；选中的模型支持调节推理强度时，旁边会出现推理强度选择，默认使用模型自己的设置。会话开始后，工作区和预设保持不变，模型和推理强度可以在它空闲时切换，只对这个会话生效。输入框左下角的回形针可以添加文件（文本、代码、日志、CSV、JSON 或 PDF；最多五个，每个不超过 20 MB），随消息一起发送，也可以只发文件。

会话上方是搜索框（可以按标题或工作区名找会话）、旁边的视图选项和**新会话**按钮。默认情况下会话的分组和 DSH 自己的侧栏一致：先按 DSH 中的顺序列出各个工作区，组内顺序也和 DSH 相同，最后是**未分组**，新的在前；每组里置顶的排在最前，点组名可以收起。视图选项可以同时显示或只显示已归档的会话；可以按工作区分组、按工作区树（每个工作区放在包含它的已注册文件夹下）或在单个列表中显示；可以按 DSH 自己的顺序或最近更新排序。这些选项按电脑保存在当前浏览器里。按工作区分组需要那台电脑上的 DSH Teamwork 插件是最新版，旧版的会话全部放在**未分组**。会话末尾的 **⋯** 可以置顶、重命名、复制会话 ID 或归档，和 DSH 自己的侧栏一致，两边都会看到变化。已归档的会话默认隐藏（当前打开的除外）；运行中的会话要等它停下才能归档。这个菜单需要那台电脑上的 DSH Teamwork 插件是最新版，旧版只能复制 ID。手机 App 里长按会话打开同样的菜单。

电脑设置按钮左边的闹钟按钮打开**自动化任务**，列出这台电脑会自动发送的指令：在选定时间发送一次、每隔几分钟、每天、每周的指定几天，或按指定时区的 Cron 表达式。**新建任务**需要填写名称、指令、运行时间和发送位置：新会话之后一直复用、每次都新建会话，或已有会话。打开任务可以看到它的重复规则、下次运行时间和发送记录，每条记录都链接到它送达的会话；**立即运行**马上发送一次，不改变下次运行时间；**暂停**、**编辑**、**删除**照字面执行。在会话里让 agent 创建或修改任务，结果也是这些任务。有任务发到、或由任务创建的会话，**文件**旁边会出现闹钟，显示有几个进行中的任务发到这个会话。点开可以看到这些任务，每个都能**立即运行**、**暂停**或**恢复**；如果这个会话是由“每次都新建会话”的任务创建的，也会列出那个任务；还可以**为这个会话新建任务**，或查看这台电脑的全部任务。任务发来的每条指令都会标明来自哪个任务、原定什么时间。没有任务的会话不显示闹钟，可以在**自动化任务**里新建，在“发送到”中选择该会话。只有那台电脑上的 DSH 在运行时任务才会执行；关机期间错过的任务，会在 DSH 再次启动时补发一次。自动化任务需要那台电脑上的 DSH Teamwork 是 0.19.10 或更新版本。

点击电脑名旁的设置按钮打开电脑设置。在这里可以给电脑改名，名称会显示在 Teamwork、手机和原生 DSH Web 中，电脑重新连接后保持不变。在电脑的 Teamwork 面板中打开原生 DSH Web 后，也可以从这里在新标签页中打开它。这里还列出与这台电脑配对的所有手机和浏览器，**移除**会立即断开其中任何一个，丢失的手机也可以这样处理。PIN 输错次数过多时，请在那台电脑的 DSH 里运行 `/teamwork pin reset`。

在电脑设置页，或电脑离线时，可以使用**移除这台电脑**：即使它仍在连接，也会立即退出 Teamwork，并连同所有已配对的设备一起从列表中移除。适用于丢失或不再使用的电脑，或重新登录后留下的旧记录。之后如果它再次登录，会重新出现，需要重新配对。

DSH 会话支持通过回形针添加多张 PNG、JPEG、WebP 和 GIF。请选择支持识图的模型。客户端会按单图 512 KiB、每条消息合计 1.5 MiB 的限制压缩并分块上传。手机 App 还可从照片图库多选或拍照。

## agent 发布的页面

在会话里让 agent 做一份报告、演示稿、看板或图表并发布。会话中会出现一张卡片，点开即在会话旁查看；工作区下的“共享页面”列出你在本团队发布的所有页面，最新的在前，并附各个版本。让 agent 修改会生成新版本，旧版本保留。页面默认只有你能看到，agent 无法共享。点“共享”可选择“仅自己”“指定成员”或“全队开放”，团队以外的人无法打开任何页面。能读到页面的人会在“共享给我的”里看到它，并可以让自己的 agent 修改，生成署名为自己的新版本。作为所有者，你还可以改名、恢复旧版本或删除页面。团队管理员在“全部”里能看到所有页面，可以收紧读者范围或删除，但只有共享给他时才能看到内容。页面在独立地址的沙箱中运行，无法以你的身份操作 Teamwork；它仍可以全屏显示，并保存自己生成的文件，例如演示稿导出的 PDF 或 PPT，浏览器会显示每一次下载。

在手机 App 里，点页面卡片会从底部弹出约占屏幕 80% 高度的预览窗口。点右上角的浏览器图标可在系统浏览器打开当前版本。点**关闭**即可回到会话。

## 知识文档

工作区下的**知识文档**用来存放团队知道的事：术语表、产品规则、操作手册，按空间和文件夹整理。侧栏中知识文档下面列出各个空间：点知识文档本身会打开所有空间的总览，点某个空间则只显示它的文件夹和文档，并列出最近更新的文档。用顶部的搜索框按标题查找文档。文档用 Markdown 书写、以排版后的样子显示；写 `[[另一篇文档]]` 或 `[[另一篇文档#某个标题]]` 就能链接到团队里同名的文档，找不到对应标题时会显示为失效链接。

每个空间都设定了谁能阅读：全队，或选定成员。空间的**编辑者**（团队管理员、空间的创建者以及空间指定的成员）可以点**编辑**修改正文，再点**保存**并附一句可选说明；每次保存都会生成一个新版本。**历史版本**列出每个版本的作者、来源和说明，可以打开任意版本、与上一版对比，编辑者还能把它恢复为一个新版本。如果你编辑期间有人先保存了，你写的内容会留在屏幕上：先和对方的版本对比，再基于新版本继续并重新保存。控制台第一次保存在别处写成的文档时，可能会整理它的 Markdown 语法；这次整理会先单独保存为一个版本，说明为**格式整理**，这样你的版本只包含你的改动。

如果你能阅读某个空间但不能编辑，照样可以点**编辑**：保存时会变成一条**修改提议**，而不是新版本。

编辑时，点**附加文件**可以给文档添加文件并插入到光标处；粘贴或拖入文件也一样。图片写作 `![[diagram.png]]`，直接显示在正文里；其他文件写作 `[[spec.pdf]]`，显示为指向它的链接。可以附加图片、PDF、文本、CSV、JSON、Word、Excel、PowerPoint 和 zip 文件，每个最多 20 MiB。文件列在正文下方，并标出正文引用了哪些。**文件名一经上传，在文档存在期间始终对应同一份内容**，所以每个版本都显示它当时的样子；要换一个文件，请用新名字附加新文件，再让正文指向它。只能阅读的成员也可以附加文件；编辑者接受引用这些文件的提议后，正文中才会显示它们。

在空行输入 `/` 可以插入块：标题、列表和任务列表、引用、**标注**、代码块、**图表**、表格、分割线，以及图片或文件。标注是一个按类型着色的框（备注、提示、警告、危险等）；编辑时可以通过两个选项设置它的类型和是否折叠，阅读时点箭头展开折叠的标注。它在文件中写作引用 `> [!warning] 标题`。图表是一个 `mermaid` 代码块：编辑时上方是源码、下方是绘制结果，阅读时只显示图。

编辑时正文上方是**属性**：文档的负责人、状态、标签和一句话摘要。阅读时它们显示在标题下方，并保存在文件的前置信息中，智能体也能读到。如果空间设置了模板文件夹，新建文档时可以选择其中的文档作为模板；模板中的 `{{title}}` 和 `{{date}}` 会替换为新标题和今天的日期。文档底部的**被引用**列出链接到它的文档。

**评论**显示在正文旁。阅读时选中文字并点**评论**，就能针对这段文字发起讨论；讨论未解决期间这段文字会保持下划线，如果后来的版本里已经没有这段文字，讨论会注明。能阅读该空间的人都可以评论和回复；发起人或编辑者可以将其**解决**。评论不属于文档内容，智能体也不会读取。

输入 `@` 可以提及成员；知识文档顶部的**提及我的**列出提到你或把你设为负责人的文档。查找框既能按标题找文档，也会在**正文中**列出包含这些文字的文档。文件夹菜单中的**以表格打开**会列出其中每篇文档的负责人、状态、标签和摘要，可按文字、状态或标签筛选，并按任意列排序。块菜单中的**共享页面**可以把你的某个共享页面嵌入为卡片；只有被共享的读者才能打开它。

你的智能体（无论在你电脑上的 DSH 还是云端 DSH）会读取你能阅读的所有空间的只读同步副本，无需指点就能找到需要的内容，并注明回答依据的文档和标题。智能体从不直接修改文档，即使在编辑者自己的会话里也一样：它只会提出修改。知识文档顶部的**修改提议**列出提给你能编辑的空间的提议（并显示等你处理的数量），以及你自己提的。打开一条即可查看改动；编辑者可以**接受**，以提议人的名义生成下一个版本，或填写理由后**拒绝**；提议人也可以**撤回**。如果提议所基于的版本之后又被修改，这条提议就**已过期**，无法接受，需要提议人基于当前版本重新提交。

## 加入多个团队

一个人可以加入多个团队。插件会同步所有团队；Teamwork 面板中的团队选择器只改变你浏览的是哪一个。

## 删除账号

在**账号设置**中选择**删除账号**。只有你一人的团队会随账号一起删除。如果你管理的团队里还有其他人，请先把管理员转给其中一人。

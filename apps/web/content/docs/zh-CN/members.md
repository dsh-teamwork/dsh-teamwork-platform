---
title: 在团队中工作
description: 在 DSH 中使用团队预设和模型、分享自己的配置、向团队助理提问。
---

登录后，团队的模型、预设和插件会出现在 DSH 里，与你自己的配置并存。在控制台里，团队打开就是**首页**，显示你近 30 天的调用和预算，以及团队最近的更新；**团队资源**列出团队提供的内容，页面上的**我的提交**链接可以查看你送审的内容；**我的用量**显示对你生效的额度、每天和每个模型花了多少积分，以及你最近的调用，并可导出这段时间的 CSV。

## 从团队预设开始

用团队预设**新建会话**，或运行 `/teamwork new <id>`。预设会带上它的模型、必需工具和锁定的插件；缺少什么，DSH 会在开始前提示你。

会话保留开始时的预设版本。要使用更新后的预设，请新建会话。

## 使用团队模型

团队模型会出现在你的模型列表中。调用经团队服务器转发，你的电脑不需要密钥，并受团队预算约束。

## 安装锁定的插件

运行 `/teamwork plugins` 查看预设依赖哪些插件，再用 `/teamwork install <id>` 预览精确版本。确认之前不会安装任何东西。

## 分享好用的配置

让团队助理把你会话中的预设或插件整理出来，或在控制台的**团队资源**里提交：上传插件、导入预设文件，或者新建预设、修改已有预设。管理员核对确切内容并批准后，所有人下次同步时就会收到。

## 向团队助理提问

每个团队都有一个助理预设。用它开一个会话，询问团队的资源、你的用量、预算、成员，或者有什么在等待审核。它要做的任何修改仍会先征求你的同意。

## 在浏览器里使用你自己的 DSH

当你某台登录了 Teamwork 的电脑上的 DSH 连接过之后，工作区会出现**我的 DSH**。这里列出这些电脑，在每个团队下都一样，每台都显示它的操作系统和已配对的设备数量。打开一台，先把这个浏览器和它配对一次：在那台电脑的 DSH 里打开 Teamwork 面板，选择**设备连接**并生成配对码，在这里输入，确认两边显示的安全码一致，再在电脑上批准。然后设置四位数的 PIN，以后回来时电脑会再次询问。之后就能在浏览器里发起、查看和回应那台电脑上的会话，浏览器和电脑之间端到端加密。每台电脑都会显示是否在线、是否已与这个浏览器配对；离线的电脑在它重新运行 DSH 之前不能操作，连上之后页面会自动继续。

新会话在页面中间等你开始，布局和 DSH 一致：发出第一条消息之前，输入框上方可以选择这台电脑的工作区和预设（包括团队预设；电脑暂时无法运行的预设会说明原因），输入框底栏可以选择模型；不改就用电脑的默认设置。发出第一条消息后，会话就在原处展开。工作区默认是这个团队在那台电脑上的默认工作区，可在 DSH 的 Teamwork 面板**我的团队**里设置。可调推理强度的模型旁边会出现强度选项。会话开始后，工作区和预设保持不变，模型和推理强度可以在它空闲时切换，只对这个会话生效。输入框左下角的回形针可以添加文件（文本、代码、日志、CSV、JSON 或 PDF；最多五个，每个不超过 20 MB），随消息一起发送，也可以只发文件。

打开的电脑下方列出最近的会话，其余的点**显示全部**；电脑那一行末尾的箭头可以把会话收起来，其他电脑就不会被挤到下面。

点击电脑旁的设备数量，可以看到与这台电脑配对的所有手机和浏览器，**移除**会立即断开其中任何一个，丢失的手机也可以这样处理。PIN 输错次数过多时，请在那台电脑的 DSH 里运行 `/teamwork pin reset`。

离线的电脑会显示**移除这台电脑**：它连同所有已配对的设备一起从列表中移除。适用于不再使用的电脑，或重新登录后留下的旧记录。仍在连接的电脑不能移除，请先在它的 DSH 里退出 Teamwork。之后如果它再次登录，会重新出现，需要重新配对。

## agent 发布的页面

在会话里让 agent 做一份报告、演示稿、看板或图表并发布。会话中会出现一张卡片，点开即在会话旁查看；工作区下的“共享页面”列出你在本团队发布的所有页面，最新的在前，并附各个版本。让 agent 修改会生成新版本，旧版本保留。页面默认只有你能看到，agent 无法共享。点“共享”可选择“仅自己”“指定成员”或“全队开放”，团队以外的人无法打开任何页面。能读到页面的人会在“共享给我的”里看到它，并可以让自己的 agent 修改，生成署名为自己的新版本。作为所有者，你还可以改名、恢复旧版本或删除页面。团队管理员在“全部”里能看到所有页面，可以收紧读者范围或删除，但只有共享给他时才能看到内容。页面在独立地址的沙箱中运行，无法以你的身份操作 Teamwork。

## 加入多个团队

一个人可以加入多个团队。插件会同步所有团队；Teamwork 面板中的团队选择器只改变你浏览的是哪一个。

## 删除账号

在**账号设置**中选择**删除账号**。只有你一人的团队会随账号一起删除。如果你管理的团队里还有其他人，请先把管理员转给其中一人。

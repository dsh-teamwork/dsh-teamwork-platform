DSH Teamwork 是 DeepSeek Harness（DSH）的团队版。团队管理员在网页控制台发布一次模型、预设和插件，每位成员的 DSH 通过 Teamwork 插件自动获取，团队模型的调用经本服务器转发，成员电脑上不保存任何提供商密钥。

## 从哪里开始

- **所有人：** 在 DSH 里[安装插件](/docs/install)，然后登录。
- **团队管理员：** [搭建团队](/docs/admins)：接入提供商、发布模型和预设、邀请成员、设置预算。要在服务器上为全团队运行一台 DSH，见[团队 DSH](/docs/team-dsh)。
- **成员：** [在团队中工作](/docs/members)：选用预设、分享好用的配置、向团队助理提问。
- **运维人员：** 用开源社区版[部署自己的服务器](/docs/self-hosting)。

## 组成部分

| 部分 | 运行在哪里 | 做什么 |
| --- | --- | --- |
| Teamwork 插件 | 每位成员的 DSH | 登录、同步团队资源、把团队模型的调用发给服务器 |
| 团队控制台 | 本网站 | 模型、预设、插件、审核、版本、用量、预算和成员 |
| 服务器 | 托管服务，或你自己的服务器 | 保管提供商密钥、每次调用核对成员身份、记录用量 |

## 什么留在哪里

- **提供商密钥**加密存放在服务器上，写入后无法读回，也不会下发到成员电脑。
- **对话**留在每位成员自己的 DSH 里。服务器转发团队模型的调用，只记录 token 数量，从不保存提示词和回复。
- **你自己的配置**仍然是你的。团队资源与它并存，不覆盖任何内容。

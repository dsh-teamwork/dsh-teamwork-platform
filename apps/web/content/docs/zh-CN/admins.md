一个团队准备就绪，需要有成员能调用的模型、可以开始的预设，以及成员本身。控制台的团队**首页**会跟踪这些步骤；团队运转起来后，首页首先列出等你处理的事项：待审核的提交、接近上限的预算、需要核对的调用，以及发送失败的预算提醒邮件。下面提到的页面在侧边栏底部的**团队管理**中，只有团队管理员能看到：展开后是**团队资产**（模型、预设、插件、审核、版本与备份）和**成员与费用**（成员、使用量、预算）。成员只看到顶部的**工作区**。

## 1. 创建团队

登录控制台，在团队列表页选择**创建团队**，你就是它的管理员。每个新团队都自带一个**团队助理**预设。

## 2. 接入提供商并发布模型

打开**模型 → 添加提供商**。从列表中选择提供商并粘贴 API 密钥，或在**自定义**中填写任意 OpenAI 兼容地址。保存前会先用这个密钥向提供商验证：提供商拒绝的密钥、或本服务器不允许调用的地址，会直接显示在表单上，并说明该怎么改。密钥加密存储，无法读回。然后勾选团队要用的模型并发布。

成员只能看到团队模型，看不到地址和密钥。

发布或编辑模型时，点击 **从公共目录填入**，系统按模型 ID 精确匹配，立即填入上下文窗口、最大输出和视觉理解能力：
OpenRouter 服务商查 OpenRouter，其他服务商查 Models.dev（Models.dev 未收录的服务商，例如自建代理，会在其所有服务商中查找这个 ID）。
按钮下方会提示数据来源和改动了哪些值，并可 **撤销**。未知字段保留已有值。
没有精确匹配，或多个服务商收录了同一 ID 时，不作更改，可通过 **选择参考模型…** 换个名称自行选择。
实际调用 ID 不会改变，保存后才生效。

在模型的参考价格表单中，计费方式为估算成本（而非内部权重）时，**填入参考价格** 以同样方式填入公开价格，
按最新参考汇率换算为人民币 / 百万文本 token 并向上取整，提示中会注明所用汇率和日期。请核对实际供应商价格后保存。
此功能仅填充表单，不定时同步，也不保存公共目录关联。

## 3. 添加预设和插件

- **预设**是团队共享的角色：调用哪个模型、需要哪些工具、按什么方法工作。可以从模板或空白预设开始。
- **插件**把 npm 包锁定到精确版本，保证所有人运行同一个构建。成员仍需在自己的 DSH 里确认安装。

每次修改都会在成员下次同步时送达，并作为一个版本保存在**版本与备份**中。

## 4. 邀请成员

打开**成员**。根据服务器的登录方式：

- **使用邮箱登录时**，创建邀请链接。链接只能使用一次，24 小时内有效。
- **使用密码登录时**，输入对方邮箱创建账号，复制显示的初始密码交给对方，它不会再显示。对方用它登录一次后，设置自己的密码。

把[安装指南](/docs/install)发给新成员。

每个团队只有一位管理员。要把管理员交给别人，在对方旁边选择**设为管理员**，你会变成成员。

## 5. 设置预算

在**模型**中为每个模型设置参考费率，然后在**预算**中按天或按月为整个团队、每位成员（默认额度）或某个提供商设置上限。每次调用在执行前按可能的最大花费预留额度，会超出上限的调用会被拒绝。预算按**积分**计算，这是团队自己的成本计量：按参考费率，1 元折合 1,000 积分。使用自己的提供商密钥时，费用仍由提供商直接向你收取。服务器能发邮件时，预算接近上限还可以邮件提醒管理员或成员。**使用量**按成员和模型列出每次调用，并可导出为 CSV。

## 6. 审核成员分享的内容

成员可以提交预设和插件。在**审核**中对比提交内容与当前线上内容，批准后发布，或填写理由后拒绝。

## 7. 运行团队 DSH

团队 DSH 是团队在自己的机器上（通常是服务器）运行的 DSH，成员通过浏览器或手机 App 在上面工作。它用**团队资产 → 团队 DSH**里的 key 登录，从不以个人身份登录；成员需要那台机器生成的邀请和自己设置的 PIN 才能加入。整个配置在控制台和那台机器的终端里完成，[团队 DSH](/docs/team-dsh) 按顺序列出了每一步和每条命令。

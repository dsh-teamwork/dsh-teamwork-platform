---
title: 搭建团队
description: 创建团队、接入提供商、发布模型和预设、邀请成员并设置预算。
---

一个团队准备就绪，需要有成员能调用的模型、可以开始的预设，以及成员本身。每个新团队都自带**团队助理**预设，托管服务上还自带平台模型。作为团队管理员，你进入团队后看到的是**团队概览**：在你自己的 DSH 接入之前，它首先引导你接入：在电脑上的 DSH 里登录 Teamwork，再把浏览器（**我的 DSH**）或手机 App 和这台电脑配对。下面跟踪团队还缺什么；团队运转起来后，首先列出等你处理的事项：接近上限的预算、需要核对的调用，以及发送失败的预算提醒邮件。团队概览位于侧边栏底部的**团队管理**最上方，只有团队管理员能看到，下面是**模型**和**成员与费用**（成员、使用量、预算）。预设和插件在工作区的**预设和插件**里管理：你看到的列表和成员一样，只是多了管理员的操作。团队管理默认是折叠的：点它或按 **Alt+M**（Mac 上是 **Option+M**）展开，选择工作区的页面后会自动收起。按 **Esc** 也可以收起团队管理。如果打开了弹窗，先按 **Esc** 关闭弹窗，再按一次收起团队管理。顶部的**工作区**对你和每位成员都一样：你自己的**首页**显示你本人的调用和预算。

## 1. 创建团队

登录控制台，在团队列表页选择**创建团队**，你就是它的管理员。每个新团队都自带一个**团队助理**预设。

## 2. 接入提供商并发布模型

打开**模型 → BYOK 模型服务**。从列表中选择提供商并粘贴 API 密钥（列表中的提供商按 [Models.dev](https://models.dev) 的 ID 命名，例如 `alibaba-cn`、`moonshotai-cn`，模型的上下文和价格也按这个 ID 去查），或在**自定义**中填写任意 OpenAI 兼容地址。Kimi 和 MiniMax 有多种账号：按密钥所属的账号选择**区域**（国内或国际）和**计费**（按量付费，或 Kimi Coding Plan、MiniMax Token Plan 订阅），地址和名称会随之填好。每种账号在公共目录里是独立条目，模型 ID 和价格各不相同；订阅套餐的模型参考价格按 0 导入，成员调用不占用预算，密钥要用订阅生成的那一个。保存前会先用这个密钥向提供商验证：提供商拒绝的密钥、或本服务器不允许调用的地址，会直接显示在表单上，并说明该怎么改。密钥加密存储，无法读回。然后勾选团队要用的模型：勾选时会自动查询它的公开参考并显示在旁边；发布时，每个模型自动带上提供商或参考给出的上下文窗口，以及按下文**填入参考价格**的方式由公开价格换算出的参考单价，这样发布的模型可以立即调用。没有精确且一致的参考价的模型发布后没有单价，设好之前无法调用（点它的**设置单价**，有参考时打开即已填好）；模型页和团队概览会一直提示，模型页上的**按参考价填写**可以一次为所有这类模型重试。单价可以为 0。单价绑定在设置时的上游模型上，模型改指向别的上游模型后需要重新设置。

控制台和手机 App 中凡是显示提供商或模型的地方，都会配上厂商的图标。

成员只能看到团队模型，看不到地址和密钥。

手动填写模型 ID 或编辑模型时，点击 **从公共目录填入**，系统按模型 ID 精确匹配，立即填入上下文窗口、最大输出和视觉理解能力：
OpenRouter 服务商查 OpenRouter，其他服务商按名称（名称不匹配时按地址）对应到列表中的条目，在 Models.dev 的该条目下查找（对应不到任何条目的服务商，例如自建代理，只能按完整 ID 在 Models.dev 的所有服务商中精确查找，找不到时会给出说明）。
按钮下方会提示数据来源和改动了哪些值，并可 **撤销**。未知字段保留已有值。
没有精确匹配，或多个服务商收录了同一 ID 时，不作更改，可通过 **选择参考模型…** 换个名称自行选择。
实际调用 ID 不会改变，保存后才生效。

提供商和模型 ID 精确匹配时，公共目录也可填入可选推理档位。发布前可检查或编辑档位。插件同步后，成员可在 DSH、App 和 Web 的模型菜单中选择档位。全部留空时使用提供商默认设置。

在模型的参考价格表单中，计费方式为估算成本（而非内部权重）时，**填入参考价格** 以同样方式填入公开价格，
按最新参考汇率换算为人民币 / 百万文本 token 并向上取整，提示中会注明所用汇率和日期。请核对实际供应商价格后保存。
此功能仅填充表单，不定时同步，也不保存公共目录关联。

在 BYOK 模型的编辑页可设置**视觉理解**，也可点**从公共目录填入**。

## 3. 添加预设和插件

两者都在**预设和插件**里。你在这里添加的是团队自己的，会出现在每位成员的 DSH 里，除非成员自己移除。

- **预设**是团队共享的角色：调用哪个模型、需要哪些工具、按什么方法工作。可以从模板（写作助手、数据分析师、调研分析师、PPT 讲稿大师）或空白预设开始，并为它选一个头像，成员在控制台和手机 App 里都会看到。PPT 讲稿大师会梳理汇报思路，写好每页内容和逐页讲稿，并把演示稿发布成页面，可以全屏演示，也能导出 PDF 和可编辑的 PPT 文件。调研分析师会阅读一手资料，发布带编号引用、缺口说明和来源日期的调研报告，可导出 PDF 和 Markdown；网页搜索方面，服务器提供搜索时（托管服务提供），成员在 DSH「网页搜索与抓取」里选择 **Teamwork** 即可，也可以自己配置 DeepSeek API 密钥；两者都没有时，它直接读取能打开的网页。
- **插件**把 npm 包锁定到精确版本，保证所有人运行同一个构建：在插件标签页点**按 npm 包添加**。成员仍需在自己的 DSH 里确认安装。

每次修改都会在成员下次同步时送达，并作为一个版本保存在**版本记录**中，入口在预设和插件页面顶部。

## 4. 邀请成员

打开**成员**。根据服务器的登录方式：

- **使用邮箱登录时**，创建邀请链接。链接只能使用一次，24 小时内有效。
- **使用密码登录时**，输入对方邮箱创建账号，复制显示的初始密码交给对方，它不会再显示。对方用它登录一次后，设置自己的密码。

把[安装指南](/docs/install)发给新成员。

每个团队只有一位管理员。要把管理员交给别人，在对方旁边选择**设为管理员**，你会变成成员。

要删除团队，在**成员**页底部选择**删除团队**并输入团队名称。所有成员会立即失去这个团队，它的模型、预设、插件、版本、用量和预算会一并删除。此操作无法撤销。

## 5. 设置预算

每个模型在第 2 步已经有了参考费率。在**预算**中按天或按月为整个团队、每位成员（默认额度）或某个提供商设置上限。每次调用在执行前按可能的最大花费预留额度，会超出上限的调用会被拒绝。只有服务器能算出最大花费的模型才能在启用的预算下运行：目前是 DeepSeek 官方 API 和托管服务提供的模型。预算启用期间，调用你自己接入的其他提供商会被拒绝。预算按**积分**计算，这是团队自己的成本计量：按参考费率，1 元折合 1,000 积分。使用自己的提供商密钥时，费用仍由提供商直接向你收取。服务器能发邮件时，预算接近上限还可以邮件提醒管理员或成员。**使用量**按成员和模型列出每次调用，并可导出为 CSV。

## 6. 推荐成员分享的内容

在**预设和插件**里打开成员分享的预设或插件，点**推荐给全队**：这个版本会在每位成员下次同步时进入他们的 DSH，可以另起一个团队里显示的名称。作者发布新版本后，这一行会提示推荐待更新，**待更新推荐**筛选会把它们集中起来；看过改动后点**推荐 v…**即可更新。**取消推荐**不影响自己添加的人；**下架**会把它从所有人的列表里移除，已经在用的人会保留。

## 7. 共享团队的知识

在**知识文档**中（侧栏知识文档下方或总览页上），为每类知识点**新建空间**：术语表、产品规则、操作手册。新空间对全队可读。空间菜单可以添加文件夹和文档；**空间设置**可以重命名、把阅读范围限定给选定成员、指定除你以外的编辑者、选择存放模板文档的文件夹，或连同其中所有内容一起删除。每位成员的智能体会读取该成员能读的空间并提出修改，由空间的编辑者在**修改提议**中处理。

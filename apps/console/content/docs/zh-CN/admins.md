---
title: 搭建团队
description: 创建团队、接入提供商、发布模型和预设、邀请成员并设置预算。
---

一个团队准备就绪，需要有成员能调用的模型、可以开始的预设，以及成员本身。控制台的团队**概览**会跟踪这些步骤；团队运转起来后，概览首先列出等你处理的事项：待审核的提交、接近上限的预算、需要核对的调用，以及发送失败的预算提醒邮件。

## 1. 创建团队

登录控制台，在团队列表页选择**创建团队**，你就是它的管理员。每个新团队都自带一个**团队助理**预设。

## 2. 接入提供商并发布模型

打开**模型 → 添加提供商**。从列表中选择提供商并粘贴 API 密钥，或在**自定义**中填写任意 OpenAI 兼容地址。密钥加密存储，无法读回。然后勾选团队要用的模型并发布。

成员只能看到团队模型，看不到地址和密钥。

## 3. 添加预设和插件

- **预设**是团队共享的角色：调用哪个模型、需要哪些工具、按什么方法工作。可以从模板或空白预设开始。
- **插件**把 npm 包锁定到精确版本，保证所有人运行同一个构建。成员仍需在自己的 DSH 里确认安装。

每次修改都会在成员下次同步时送达，并作为一个版本保存在**版本与备份**中。

## 4. 邀请成员

打开**成员**。根据服务器的登录方式：

- **使用邮箱登录时**，创建邀请链接。链接只能使用一次，24 小时内有效。
- **使用密码登录时**，输入对方邮箱创建账号，并把显示的初始密码交给对方；对方首次登录时需要修改。

把[安装指南](/docs/install)发给新成员。

每个团队只有一位管理员。要把管理员交给别人，在对方旁边选择**设为管理员**，你会变成成员。

## 5. 设置预算

在**模型**中为每个模型设置参考费率，然后在**预算**中按天或按月为整个团队、每位成员（默认额度）或某个提供商设置上限。每次调用在执行前按可能的最大花费预留额度，会超出上限的调用会被拒绝。**使用量**按成员和模型列出每次调用，并可导出为 CSV。

## 6. 审核成员分享的内容

成员可以提交预设和插件。在**分享与审批**中对比提交内容与当前线上内容，批准后发布，或填写理由后拒绝。
